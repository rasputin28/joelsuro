## Qué cubre el examen

Microsoft evalúa cinco dominios. Los pesos son estimaciones oficiales (pueden variar ±5%):

| Dominio | Peso |
|---|---|
| 1. Identidades y gobernanza (Azure AD, RBAC, políticas, suscripciones) | ~20-25% |
| 2. Almacenamiento (Blob, Files, redundancia, acceso) | ~15-20% |
| 3. Cómputo (VMs, App Service, containers, escala) | ~20-25% |
| 4. Redes virtuales (VNet, NSG, Load Balancer, DNS, VPN) | ~15-20% |
| 5. Monitoreo y mantenimiento (Monitor, Alerts, Backup, Site Recovery) | ~10-15% |

Formato: ~50-60 preguntas, 150 min, puntaje mínimo 700/1000.

## Materiales

**Gratuitos:**
- [Microsoft Learn — ruta AZ-104](https://learn.microsoft.com/es-es/credentials/certifications/azure-administrator/) — sigue el orden del plan semana a semana
- John Savill's AZ-104 Study Cram — YouTube, ~4h, excelente para repasar antes del examen
- Azure Free Account (12 meses) — para todos los labs; no cuesta nada si se usan los recursos del tier gratuito

**De pago (recomendados, no obligatorios):**
- Whizlabs AZ-104 (~$20) — banco de preguntas con explicaciones
- MeasureUp AZ-104 (~$99) — el simulacro más cercano al examen real; Microsoft lo recomienda oficialmente
